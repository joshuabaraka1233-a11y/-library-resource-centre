# Library And Resource Centre

A responsive Next.js website concept for Library And Resource Centre, Ngong Road, Nairobi.

## Pages

- / — Homepage and visitor overview
- /about — About the centre
- /discover — Reading, learning and visitor information
- /reviews — Google rating and featured visitor comment
- /contact — Phone, location, directions and embedded map

## Technology

- Next.js App Router
- React and TypeScript
- Tailwind CSS 4
- Lucide icons
- Responsive custom CSS

## Run locally

Requirements: Node.js 24 (or a compatible supported version) and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Verify before deployment

```bash
npm run lint
npm run build
```

GitHub Actions runs both checks for pushes and pull requests to main.

## Before going live

1. Confirm all institutional information with library management.
2. Confirm the phone number, location pin, opening hours and review details.
3. Replace demonstration photography with approved library photographs where available.
4. Set the production domain and deployment environment.
5. Add any official email, enquiry form or online catalogue only after the required details and services are provided.
